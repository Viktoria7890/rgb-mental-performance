# Работоспособность по RGB-сигналам лица

Проверяла, можно ли по цвету лица на видео предсказать умственную работоспособность человека. Данные: 10 участников, из видео взят 1 кадр в секунду, цвет усреднён по области лица и порезан на минуты. На каждую минуту есть оценка работоспособности `AU`.

## Что сделала

- классификация (высокая/низкая работоспособность, порог по медиане) и регрессия;
- признаки для ML: статистики, тренд, автокорреляция, спектр, связи между каналами;
- 8 моделей: LogReg/Ridge, SVM, kNN, Random Forest, Extra Trees, XGBoost, LightGBM, CatBoost;
- 5 нейросетей на сыром сигнале: 1D-CNN, LSTM, GRU, CNN+LSTM, Transformer;
- 7 наборов каналов (R, G, B, RG, RB, GB, RGB), всего 182 конфигурации;
- валидация Leave-One-Subject-Out: тест всегда на человеке, которого модель не видела.

## Результат

На новых людях ни одна модель не работает лучше случайного угадывания.

| | лучший результат | бейзлайн |
|---|---|---|
| классификация | F1 0.50, ROC-AUC 0.51 | 0.50 |
| регрессия (1D-CNN, G+B) | RMSE 0.907 | 0.922 (среднее) |

Чтобы убедиться, что это не ошибка в коде, я обучила ту же модель 50 раз на перемешанных метках. Настоящая модель от них не отличается (p ≈ 0.33).

## Утечка данных

Оценка ставится на всю сессию, а не на минуту: внутри сессии около 5 минут с одной меткой. Независимых меток не 1055, а 211. Из-за этого результат сильно зависит от того, как делить данные:

| разбиение | ROC-AUC (LightGBM) |
|---|---|
| случайно по минутам | 0.74 |
| по сессиям | 0.52 |
| по участникам | 0.42 |

0.74 получается потому, что минуты одной сессии попадают и в train, и в test, и модель узнаёт запись по освещению и позе. К усталости это отношения не имеет.

ROC-AUC ниже 0.5 тоже объясним. Участники сильно отличаются по среднему уровню `AU`, и когда в тест уходит человек с высоким уровнем, в train остаются в основном низкие. Предсказания смещаются в обратную сторону: среднее по train коррелирует с настоящим `AU` на −0.59.

## Ограничения

При 1 кадре в секунду из сигнала не достать пульс и его вариабельность, а это главные физиологические признаки усталости. Плюс данных мало: 10 человек.

## Запуск

Данные участников в репозиторий не выложены, это материалы курса. Чтобы запустить, нужна папка `data/` с подпапками `R/`, `G/`, `B/` рядом с ноутбуком.

В `results/` лежат уже посчитанные метрики и предсказания, с ними ноутбук проходит за минуту. `RECOMPUTE = True` переобучит всё заново, это около часа на CPU.
